# A-CARD Platform Walkthrough Videos

Screen-recorded walkthroughs of the A-CARD dashboard, captured at 1600×1000 resolution.

## Videos

### A-CARD-full-walkthrough.mp4 (2:56, 8.7 MB)
Complete end-to-end demonstration covering both personal and enterprise consoles.

### A-CARD-personal-console.mp4 (1:32, 4.5 MB)
Personal console walkthrough featuring:
- Sign-in and home view (wallet + agent cards)
- Real-time authorization scenarios:
  - Approved purchase (Checkers Sixty60, within limits)
  - Declined purchase (Steam, merchant category not allowed)
  - Held for approval (FlySafair, above threshold)
- Approvals queue (human-in-the-loop approval)
- Wallet management, card configuration, spending history, and MCP integration

### A-CARD-enterprise-console.mp4 (1:21, 4.3 MB)
Enterprise workspace walkthrough featuring:
- SSO login (Aurora Industries org)
- Overview dashboard (fleet metrics, spend summary, pending approvals)
- Agent fleet management (per-department card allocation)
- Department budgets (shared monthly allocations)
- Org policies (merchant categories, approval thresholds)
- Live activity (authorization engine in action)
- Approvals queue (with department context)
- Finance dashboard (spend by department vs budget)
- Audit log (complete authorization history)
- Team & roles management (RBAC across org)
- MCP workspace scoping

## Usage

Videos are embedded captions in the a·card brand style:
- **Kicker** (label): IBM Plex Mono, #4fd695 green, uppercase
- **Text** (description): IBM Plex Sans, cream (#f2f6f2), left-aligned caption bar at bottom

All scenarios use sandbox/mock data and test cards (4242-prefixed).
